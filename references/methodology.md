# 影响因素挖掘 · 方法选型与解读参考

本文件供需要解释「为什么用这种方法、如何解读结果」时加载。

## 1. 目标变量类型决定分析方向

| 目标变量 Y | 分析方向 | 单因素检验 | 首选模型 |
|---|---|---|---|
| 连续（价格、销量、评分、金额） | 回归 | Pearson/Spearman 相关 | 随机森林/XGBoost 回归 |
| 二分类（是否流失、是否成交） | 分类 | 点二列相关 / t 检验 | 随机森林/XGBoost 分类 |
| 多分类/有序 | 分类 | ANOVA F / 卡方 | 随机森林/XGBoost 分类 |

判定规则：`nunique <= 20` 且为字符串/类别 → 分类；否则 → 连续。

## 2. 各指标的含义与解读

### 单因素相关性
- **Pearson 相关系数**：线性相关，[-1, 1]，绝对值越大线性关系越强。适用于连续-连续。
- **Spearman 秩相关**：单调相关，对非线性单调关系更稳健。
- **ANOVA F 值**：数值特征对不同类别 Y 的区分能力，越大越显著。
- **卡方检验**：分类特征与分类 Y 的独立性，p<0.05 表示相关。

### 特征重要性（多因素建模核心）
- **树模型 MDI（Gini/方差重要性）**：特征在分裂中被用到的程度。直观但会偏向高基数特征。
- **排列重要性（Permutation Importance）**：打乱该特征后模型性能下降多少，更稳健，推荐作为最终排序依据。
- **标准化回归系数**：线性模型中每单位标准差变化对 Y 的贡献，符号即「正/负影响方向」。

### 何时用哪种
- 想快速排序 → 树模型重要性。
- 想要「方向」（正影响还是负影响）→ 线性模型系数。
- 想要稳健、可解释的最终结论 → 排列重要性 + 线性系数结合。

## 3. 常见误区

1. **相关性 ≠ 因果性**：模型输出的是统计关联和预测贡献，不代表「X 导致 Y」。因果推断需要干预实验、对照设计或工具变量等额外设计。
2. **共线性**：两个特征高度相关（|r|>0.85）时，重要性会被拆散，二者单独看都不高。应先识别并提示，必要时合并或去重。
3. **高基数偏置**：类别特别多的特征（如 ID、编号）在树模型里容易虚高，应排除或合并低频类。
4. **小样本过拟合**：样本 < 特征数×10 时，树模型易过拟合，建议改用 LASSO/Ridge 正则化。
5. **缺失值直接删除**：会丢信息、引入偏差，优先填充（数值中位数、分类众数）。

## 4. 文本列量化的方法

- **TF-IDF 关键词频次**：提取高频关键词作为 0/1 或加权特征，适合「有无提及某概念」。
- **情感打分**：正/负/中性评分，适合评论、反馈类文本。
- **主题标签**：LDA 等主题模型，适合长文本、需要抽象归纳时。

量化结果作为新数值列并入特征矩阵，再统一走单因素 + 多因素流程。

## 5. 输出解读建议

最终向用户交付三块：
1. **重要性排序表**：因素、重要性、方向（正/负）、一句话说明。
2. **可排除因素**：单因素不显著且重要性极低的特征，明确说「这些基本无关」。
3. **风险提示**：共线性、样本量、因果性边界。
